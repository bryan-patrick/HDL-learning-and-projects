# The main HDL-related file extensions

## .v (Verilog)

- HDL source, used for modules, logic, testbenches, etc. I think this is the standard extension.

## .sv (System Verilog)

- This is a superset of Verilog. IT includes upgraded types, interfaces, assertions, classes, and validation.

## .vh (Verilog Header)

- Shared macros, consts, or defs included by the .v files (we'll see how later?)
- Similar to a C file

## .svh (System Verilog Header)

- Same idea as the .vh but for .sv

## .vhd or .vhdl

- Similar to Verilog (another hardware description language) but more verbose and strongly typed
